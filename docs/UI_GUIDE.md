# UI 规范

已上线页面的观感是基线。**改功能时复用现有变量和组件，不要另起一套皮肤。**

## 气质

- 黑底、低对比玻璃/细线、少量紫青 accent
- 极简：少徽章、少装饰文案、不堆入口
- 数字世界感：克制动效，避免花哨渐变堆砌

## 作品画布

用户自选方向（编辑器新建）：

| 方向 | 比例 | 设计画布 |
|---|---|---|
| `landscape` | 16:9 | 1920×1080 |
| `portrait` | 9:16 | 1080×1920 |

实现上压缩/预览常用标准档（约 1280 宽）与 `hd`。播放区按作品 `orientation` 留画幅，不要把竖屏作品拉成横屏。

## 样式从哪抄

| 区域 | 文件 |
|---|---|
| 首页四世界 | `public/index.html` 内联 CSS（独立气质，勿用 workspace 覆盖首页） |
| 幻想制作 / 编辑器 | `public/workspace/css/workspace.css` + 页内补充 |
| 广场 / 部分彼岸页 | 页内 `:root`（`--accent` 等） |

作品编辑器已有：剪映式时间线积木（拖把手调序、行内改字、文件拖入挂画面/配音）、底栏加块芯片、顶栏试玩、播放 overlay、聊天框式对白。改播放文字先看 `story-editor.html` 里现有 class，不要重做一套字幕。交互层原则：时间线积木拖排，不为拖而拖。

- 增加未在 `FEATURES.md` 出现的常驻入口
