所有编解码在本机浏览器完成（libwebp / libavif / MozJPEG / OxiPNG WASM），不会上传图片。

基于浏览器端 ONNX 的 AI 抠图，本地推理，不上传图片。首次运行需下载模型（约 40MB），之后由浏览器缓存。

点帧条缩略图选中当前帧；选中帧可删除 / 复制。动图 WebP 的编码导出暂未内置（可导入、逐帧编辑，再导出 GIF / APNG）。

打码 / 裁剪 / 旋转会实时绘制到输出。容器取决于浏览器：Chrome/Edge/Firefox → WebM；Safari → 可选 MP4。
时长过长时建议用「GIF 动图」采样导出。

一键套用平台尺寸 / 格式 / 质量。选择后立即预览并切换到「压缩」页，可再调整后导出。

当前「处理 / 压缩」设置将应用到列表中的每个文件（动图/视频除外）。

处理完成后可逐个下载，或「下载全部」。
